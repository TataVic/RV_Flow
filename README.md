# RV Flow

Sistema de gestão desenvolvido para a RosiVelasco, com foco no controle de estoque, vendas, compras e financeiro.

## Objetivo

Centralizar a gestão da empresa em uma única plataforma, permitindo o acompanhamento de produtos, movimentações de estoque, vendas e fluxo financeiro.

## Funcionalidades

- Cadastro de produtos
- Controle de estoque
- Entrada e saída de mercadorias
- Registro de vendas
- Controle financeiro
- Relatórios gerenciais
- Dashboard com indicadores

## Tecnologias

- Flutter
- Dart
- Supabase
- PostgreSQL
- Riverpod
- Git
